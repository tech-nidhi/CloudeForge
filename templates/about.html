About {{ app_name }}

CloudForge is a hands-on learning application built to demonstrate the journey from local development to containerized deployment on AWS.

In this workshop, students take a lightweight Flask application running on localhost, package it into a self-contained Docker container, and deploy it onto an Amazon Web Services (AWS) EC2 instance.

1. CODE Python / Flask
➔
2. CONTAINER Docker Image
➔
3. CLOUD AWS EC2
➔
4. INTERNET 0.0.0.0:5000
