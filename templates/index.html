📖 About CloudForge

Workshop Overview

CloudForge is a hands-on learning application built to demonstrate the journey from local development to containerized deployment on AWS.

1. Local Development Fast iteration with Python and Flask on localhost:5000.
2. Container Packaging Reproducible environments with Dockerfile & lightweight images.
3. Cloud Deployment Running containers reliably on AWS EC2 across the globe.
